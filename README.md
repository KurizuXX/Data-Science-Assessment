## 🚀 Descripción del Proyecto
Este repositorio contiene el desarrollo colaborativo de código aplicando buenas prácticas de control de versiones, flujos de trabajo basados en ramas (feature branches), resolución de conflictos y revisiones cruzadas.

## 🛠️ Workflow del Equipo
Para este proyecto hemos definido las siguientes reglas de trabajo:
1. **Rama principal (`main`):** Contiene el código funcional y aprobado.
2. **Ramas de desarrollo (`feature/`):** Cada integrante trabaja sus tareas de forma aislada en ramas independientes.
3. **Integración:** Todo cambio pasa obligatoriamente por un Pull Request y una revisión de código antes de integrarse.
